# Close a POB (Sub-Item) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the admin close/reopen an individual POB (sub-item); a closed POB takes no new claims except filling empty member slots in already-secured (whole-set) sets.

**Architecture:** Mirror the existing `secured_sets` flag pattern. A new backend `closed_subitems` store (keyed `go_id, sub_item_id`) is loaded into a frontend `closedSubItems` map and stamped onto each rebuilt sub-item as `si.closed`. Claim placement (buyer `submitClaim` set path, admin `logSetClaim`) and the buyer picker consult a shared rule: when closed, a member is claimable only if a `status==='secured'` set has that member's slot empty. Whole-GO close is folded into the same rule.

**Tech Stack:** Single-file `index.html` (vanilla JS) + `go-manager-backend.gs` (Google Apps Script) + Google Sheets. No build, no test framework.

## Global Constraints

- Edit only `index.html` and `go-manager-backend.gs`.
- "Secured by set" = `set.status === 'secured'` (already means flagged-or-full after the secured-set-flag feature). "Secured by individual members" = `set.status === 'open'` with individual secured slots — has **no** leftover.
- Leftover-claimable = an **empty** member slot in a `status === 'secured'` set.
- A closed POB: `go.status === 'closed' || si.closed`. Never create a new set and never fill a non-secured set when closed.
- Persist writes via `persistWrite(apiPost(...), label)` (surfaces failures + resyncs).
- Backend follows the `secured_sets` shape exactly (sheet + `getX`/`setX` + routing + `deleteGO` cleanup + `bootstrapSheets()` in the setter).

function isSubItemClosed(goId, siId) { return !!closedSubItems[goId + '|' + siId]; }
